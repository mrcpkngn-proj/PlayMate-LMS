📖 Quiz Maker Guide

Everything you need to know about creating a quiz.

1

Classwork Details

Enter the basic information for the classwork associated with your quiz.

  • Provide the required classwork information.
  • Make sure the details are correct before creating or saving the quiz.
2

Quiz Settings

Configure the general settings of your quiz. These settings determine how the quiz will behave for students.

3

🤖 A.L.E.C. Smart Assist

A.L.E.C. can suggest questions based on limited topics at the moment (e.g Mathematics, Grammar, Science).

  1. Enter one or more topics in the topic field.
  2. Separate multiple topics using commas. Example: Mathematics, Grammar, Science
  3. Click Suggest Questions.
  4. Review the suggested questions.
  5. Click Add to Quiz to add the suggestions to your quiz.
  6. Click Discard if you do not want to use the suggestions.
💡 Tip: Always review AI-generated questions before adding them to your quiz.
4

📝 Adding Questions

Click + Add Question to create a new question.

Each question contains several settings:

  • Per-Question Timer — Set how many seconds the student has to answer the question. This timer is for each question and is separate from the quiz duration timer.
  • Points — Set how many points the question is worth.
  • Question Text — Enter the question that will be shown to students.
5

✅ Answer Type

Each question can use one of two answer types.

Single Correct Answer Students can select only one correct answer.
Multiple Correct Answers More than one choice can be marked as correct.
6

🔘 Choices

Add the possible answers for the question.

  • Click + Add Choice to create another answer choice.
  • Enter the choice text.
  • Mark the correct answer using the Correct answer selector.
  • Use Remove to delete an unwanted choice.
⚠️ Make sure every question has the appropriate correct answer(s) selected.
7

🗑️ Removing Questions

If you no longer want a question, click Remove Question at the bottom of that question.

8

💾 Finishing Your Quiz

  • Create Quiz — Saves a new quiz.
  • Save Changes — Updates an existing quiz.
  • Cancel — Leaves the quiz maker without submitting the form.
🚀 Before saving: Check your questions, timers, points, choices, and correct answers.
